OrGigs Installer

Installs OrGigs on an M-VAVE SMK-37 Elite or an M-VAVE FM-1 over USB, right from this page. The page finds out which of the two is connected and picks its package.

Details

  


  
Before you start

  
    
    
  • Use Chrome, Edge or Firefox on a computer (they speak Web MIDI) and allow MIDI access with SysEx when
      asked (Firefox asks to add a site permission for it).
    • 
    
  • Windows, first install over M-VAVE's own firmware: use Firefox. Chrome and Edge freeze when the keyboard
      switches to update mode (a bug of theirs on Windows with the stock firmware's three MIDI ports). Updating OrGigs
      works in all three.
    • 
    
  • Connect only the keyboard you install on, with a USB data cable. Close other programs that use its
      MIDI port (DAWs, M-VAVE's app, other browser tabs).
    • 
    
  • Updating OrGigs keeps your setups and settings. Coming from another firmware, OrGigs starts with its factory
      settings.
    • 
    
  • Don't unplug the keyboard while it installs. If the write is cut off, plug it in again and press Install: it
      goes on where it stopped.
    • 
  


  

    
SMK-37 Elite: it needs M-VAVE's own firmware V016 (or a custom firmware) before the first install; update an
      older one with M-VAVE's updater first. The stock firmware, or another custom one, clears OrGigs's settings when it
      starts: make a backup first (manual, chapter 7). OrGigs never touches the Elite's Bluetooth pairing or its key and
      pad calibration.

    
The SMK-37 Pro and MKE-P37 are the same keyboard under other names, but OrGigs is tested only on the Elite.

  


  
Going back

  
    
    
  • Install the stock firmware with M-VAVE's updater, or any other firmware from
      The Firmware Hub.
    • 
    
  • If the keyboard doesn't start normally, hold OCT− while switching it on: it starts in USB rescue mode,
      ready for an installer.
    • 
  


  
Installing custom firmware is at your own risk. OrGigs is free software under the GPL-3.0; the
    update protocol is Felucca's (Leo Kuroshita, Hügelton Instruments), as Skiff (illuminus5) carries it.
